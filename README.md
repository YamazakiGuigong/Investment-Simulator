# 倍投投资模拟器 软件介绍

## 1. 软件概述

本软件是一个**马丁格尔（倍投）策略模拟器**，用于演示和计算在有限资金、有限目标（止盈/止损）下，采用“输了加倍下注”的策略时，最终达到止盈点的概率。软件同时提供：

- **实时模拟**：通过随机数模拟每一次下注，观察资金变化、连败次数、最高投注额等。
- **理论胜率计算**：利用**马尔可夫链动态规划**精确计算从初始本金出发，最终达到止盈点的概率（非模拟，而是数值解）。
- **多线程并行计算**：理论胜率计算使用 OpenMP 并行加速，并在后台线程运行，界面不卡顿。
- **暂停/继续与停止/开始**：用户可以随时暂停或继续理论胜率计算，也可以手动停止并保留最后结果。

---

## 2. 界面参数说明

### 2.1 输入参数（可修改）

| 参数名称 | 含义 | 默认值 |
|---------|------|--------|
| **本金** | 初始资金总额 | 200.000 |
| **胜率(0-1)** | 单局获胜的概率（0~1之间） | 0.500 |
| **单次投资收益** | 赢时盈利占投注额的比例，例如 0.995 表示赢时赚投注额的 0.995 倍 | 0.995 |
| **止损点** | 当资金 **小于** 该值时停止模拟（触发止损） | 1.000 |
| **止盈点** | 当资金 **大于等于** 该值时停止模拟（达到止盈） | 250.000 |
| **初始投注** | 每轮倍投开始时的第一注金额 | 1.000 |
| **倍投因子** | 每次输后下注额乘以此因子，例如 2 表示 1,2,4,8… | 2.000 |

**其他控件：**

- **自定义次数输入框**：可输入任意正整数，配合旁边的“自定义”按钮，执行指定次数的模拟投注。
- **理论胜率显示区域**：显示“达到止盈点胜率”，以及当前状态（计算中、停止中、已计算完成等）。
- **停止计算 / 开始计算**：控制理论胜率的计算（详见后文）。
- **日志窗口**：显示操作记录和模拟结束信息。

## 3. 倍投策略规则

1. 每轮从 **初始投注额** 开始下注。
2. 若 **赢**：资金增加 `投注额 × 单次投资收益`，同时投注额重置为初始投注额。
3. 若 **输**：资金减少 `投注额`，投注额乘以 **倍投因子**，用于下一局。
4. 如果下一局所需投注额超过当前资金，则投注额重置为初始投注额（重新开始倍投）。
5. 如果初始投注额仍超过资金，或资金触及止损/止盈，则停止整个模拟。

**例子**：初始投注 1，倍投因子 2，胜率 0.5，收益系数 0.995。
- 连续输 5 次：亏损 1+2+4+8+16=31，下一注 32；
- 若资金不足 32，则重置为 1 重新开始。

## 4. 理论胜率计算算法

### 4.1 数学模型

理论胜率计算基于**马尔可夫链**模型。将“当前资金 C”和“当前应下注额 b”作为状态 `(C, b)`，定义 `P(C, b)` 为从该状态出发最终达到止盈点的概率。

**边界条件：**
- `P(C, b) = 0`，若 `C < 止损点`
- `P(C, b) = 1`，若 `C ≥ 止盈点`

**递推方程：** 当 `止损点 ≤ C < 止盈点` 且 `b ≤ C` 时：
```
P(C, b) = 胜率 × P(C + 收益系数×b, 初始投注) + (1-胜率) × P(C - b, b×倍投因子)
```
若 `b > C`（资金不足以按当前投注额下注），则投注额重置为初始投注额，再判断是否可继续。

### 4.2 数值求解方法

由于状态连续且无穷，需离散化：
- 资金离散为步长 `Δ = 0.001` 的格点；
- 投注额仅能取 `初始投注 × 倍投因子^k` 的有限序列；
- 使用**雅可比迭代（值迭代）**：先初始化概率数组，然后反复用递推方程更新所有状态，直到最大变化量小于 `1e-12`。

**OpenMP 并行化**：迭代中每个资金状态的计算相互独立（使用上一轮结果），因此利用 `#pragma omp parallel for` 将资金维度分配给多个 CPU 核心并行处理。

**后台线程与消息机制**：计算在 `std::thread` 中执行，周期性（每 100 次迭代）通过 `PostMessage` 向界面发送当前近似值，完成后发送最终结果。这保证了界面不卡顿。

### 4.3 暂停与继续

- 计算线程在每轮迭代开始前检查全局“暂停标志”。
- 若暂停标志为真，线程在条件变量上等待；点击“开始计算”并确认参数未变后，取消暂停并唤醒线程，从而**继续**原有计算。
- 若参数已更改，则启动一个新线程（新世代），旧线程因世代不匹配自动退出。

### 4.4 停止与显示

- 点击“停止计算”设置暂停标志，并禁止自动计算。线程暂停时，界面会显示**最后一次迭代得到的近似概率**，并括号标注“（停止中）”。
- 如果计算已经完成，显示最终精确概率并标注“（已计算完成）”。

---

## 5. 模拟与理论胜率的关系

- **模拟**是基于随机数的一次或多次实际下注，结果具有随机性。
- **理论胜率**是通过动态规划算出的精确概率（在给定参数和离散化精度下），不受随机波动影响。
- 用户可以通过大量模拟（如“一直投”多次）来验证理论胜率的正确性。

---

## 6. 使用建议

- 调整参数后，建议点击“重置”或“开始计算”以更新理论胜率。
- 若计算耗时较长，可随时“停止计算”查看当前近似值；再次点击“开始计算”若参数未变则继续，若参数已变则重新计算。
- “重置”按钮会读取所有输入参数并重置模拟状态，但**不会**在参数未变时重新计算理论胜率。

---

## 7. 技术特点总结

- **C++ / Win32 API** 图形界面，轻量高效。
- **OpenMP 多核并行**加速动态规划。
- **条件变量实现暂停/继续**，避免线程频繁创建销毁。
- **世代控制（epoch）**防止过期的计算结果覆盖新结果。
- **编辑框文本比较**精确判断参数是否变化，避免浮点误差导致误判。
- **格式化输出**小数保留三位，界面整洁。

---

## 8. 注意事项

- 编译时需在 Visual Studio 中启用 **OpenMP 支持**（`/openmp`）。
- 理论胜率计算可能耗时较长（取决于资金范围和离散精度），但并行化和后台线程有效改善了体验。
- 该策略长期期望为负，模拟器仅用于教育或分析目的，请勿用于真实赌博。
